# Цикл

Цикл повторяет блок действий. Цикл for перебирает элементы последовательности, а while выполняет блок, пока условие истинно.

**Источник.** Python Documentation: More Control Flow Tools — https://docs.python.org/3/tutorial/controlflow.html

**Пример.** Цикл `for` перебирает элементы последовательности, а `while` выполняет блок, пока условие истинно.
