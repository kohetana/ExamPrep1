# Тип данных

**Определение.** Тип данных — это характеристика значений, которая определяет, какие операции с ними допустимы и как они хранятся в памяти.

**Источник.** Python Documentation: Built-in Types — https://docs.python.org/3/library/stdtypes.html

**Пример.** Для количества элементов удобно использовать целый тип `int`, а для дробного значения — `float`. Для суммы положительных чисел выбираем `int`, если список целых чисел.

**Связь с ответами.** На этот термин ссылаются ответы «Числовые типы данных» и «Сумма положительных чисел».
