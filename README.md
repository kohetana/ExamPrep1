## Порядок проверки
1. Автор пишет ответ (status: draft).
2. Проверяющий читает ответ и связанные термины, пишет замечание в Decisions/Review.md.
3. После исправлений ответ переводится в review, затем в approved.
4. В approved ответ переводит только проверяющий после проверки содержания и ссылок.

## Структура репозитория
- `Answers/` — шесть заметок с ответами на вопросы.
- `Terms/` — три общие заметки словаря: «Тип данных», «Логическое выражение», «Цикл».
- `Decisions/` — решения команды, замечания по проверке, описание конфликта.
- `README.md` — этот файл.
- `schema.md` — согласованные свойства заметок.
- `МОС Подготовка к экзамену.md` — карта содержания.

## Правила обмена
- Перед работой: `git status`.
- Получение изменений: `git pull --ff-only`.
- После правки: `git diff`, `git add` только нужных файлов, `git commit`, `git push`.
- Force push запрещён.
- Общие термины меняем только после предупреждения команды.
