# Условный оператор

## Объяснение
Условный оператор выбирает действие по результату логического выражения. В Python это `if`, `elif`, `else`. Сначала вычисляется условие, затем выполняется соответствующая ветка.

## Пример
```python
x = 5
if x > 0:
    print("положительное")
else:
    print("не положительное")
