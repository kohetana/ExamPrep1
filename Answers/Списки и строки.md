# Списки и строки

## Объяснение
Список хранит несколько значений и позволяет перебирать их. Строка — это последовательность символов. Важно различать число и его текстовую запись: `5` — число, `"5"` — строка.

## Пример
```python
numbers = [3, -2, 0, 5]   # список чисел
text = "5"                 # строка, а не число
