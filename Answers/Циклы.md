# Циклы

## Объяснение
Цикл перебирает элементы или повторяет действия по условию. `for` удобен для перебора списка, `while` — для повторения, пока условие истинно.

## Пример
```python
total = 0
for x in [3, -2, 0, 5]:
    total += x
