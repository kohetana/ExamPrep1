# Числовые типы данных

## Объяснение
При решении задач нужно выбрать тип для количества (целое число) и для дробного значения (вещественное). В Python для целых чисел используется `int`, для дробных — `float`. Выбор типа влияет на точность и на допустимые операции.

## Пример
```python
count = 5          # int — количество
average = 2.5      # float — дробное значение
