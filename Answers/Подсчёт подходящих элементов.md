# Подсчёт подходящих элементов

## Объяснение
Задача: подсчитать числа больше заданного порога. Нужны [[Циклы]] для перебора, [[Логическое выражение]] для проверки условия и [[Тип данных]] для выбора типа счётчика (целый `int`).

## Пример
```python
numbers = [1, 5, 10, 3, 8]
threshold = 4
count = 0
for x in numbers:
    if x > threshold:
        count += 1
print(count)  # 3
