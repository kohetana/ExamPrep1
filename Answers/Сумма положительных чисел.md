# Сумма положительных чисел

Дан список целых чисел. Складываем только положительные.

## Объяснение
[[Числовые типы данных]] помогают выбрать тип суммы (`int` для целых чисел). [[Условный оператор]] объясняет проверку значения (`x > 0`). [[Циклы]] объясняют перебор всех элементов списка. Общий термин [[Цикл]] определён в словаре.

## Пример
Для списка `[3, -2, 0, 5]` ожидаем сумму `8`.

```python
numbers = [3, -2, 0, 5]
total = 0
for x in numbers:
    if x > 0:
        total += x
print(total)  # 8
